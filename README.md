# CNAP Member Hub prototype (feedback build)

A static design prototype of the CNAP Member Hub homepage, published for reviewer feedback.

- Every person, number, and event on it is fictional. Nothing is connected to CNAP's reporting system, calendar, or listserv.
- Source of truth: `design/prototypes/member-hub/` on the `feature/cnap-ui-redesign` branch. This branch only holds a copy for viewing.
- Not the production site. The reporting platform on `main` is unchanged.
